# Training deck: how CNC Process Pro works

A short Slidev presentation for the production team (operators). A ready-made PDF is in
`cnc-process-pro-training.pdf`.

```bash
cd training
npm install @slidev/cli @slidev/theme-default
npx slidev            # present at http://localhost:3030 (press F for full screen, O for overview)
npx slidev export     # re-create the PDF (needs playwright-chromium)
```

Screenshots in `public/shots/` were taken from the app with an operator account.
